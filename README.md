<p>

<a href="https://www.xbmc-kodi.cz/prispevek-sledovanitv">Vlákno na fóru XBMC-Kodi.cz</a><br><br>
</p>
<h3>Archivní pořady</h3>
<p>
Pro přehrávání archivu přes webové API zadejte do nastavení doplňku hodnotu
<code>PHPSESSID</code> z cookies přihlášeného prohlížeče pro sledovanitv.cz
do pole „Webová session“ (v nástrojích pro vývojáře prohlížeče). Při odhlášení
nebo pokud přestane fungovat, hodnotu aktualizujte. Jde o citlivý přihlašovací
údaj uložený lokálně v nastavení Kodi; nesdílejte ho ani související stream URL.
</p>
